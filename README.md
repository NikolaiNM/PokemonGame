# Битва Покемонов (Консольная версия)

Консольная игра на Java. Управление через текстовые команды.

## Стек
- Java 17
- Стандартные библиотеки (Scanner, File, PrintWriter)

## Запуск

1. Открой проект в IntelliJ IDEA.
2. Запусти `Game.java` (зелёный треугольник рядом с `main`).
3. Вводи команды в консоль.

## Команды
- `new <Имя>` — создать тренера.
- `add <Имя>` — поймать покемона (например, `add Пикачу`).
- `status` — показать статус тренера и команды.
- `search` — найти 4 диких покемонов.
- `attack <Имя> <ID>` — атаковать врага (например, `attack Пикачу 1`).
- `save` — сохранить игру.
- `load` — загрузить игру.
- `help` — список команд.
- `exit` — выйти.

## Сохранения
Файл `savegame.csv` создаётся в папке `saves/` в корне проекта.

## Структура
- `Game` — точка входа, обработка команд.
- `Trainer`, `Pokemon` — модели.
- `Battle` — логика боя.
- `PokemonSpecies` — enum с видами покемонов.
- `GameStateStorage` — сохранение/загрузка CSV.
